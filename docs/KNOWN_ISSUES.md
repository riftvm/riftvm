# Known issues for 0.1.0

## Omarchy keyboard responsiveness

Ordinary text input in an Omarchy workspace can appear late or incomplete, and
Return may appear unresponsive. This can affect login screens as well as desktop
applications. The issue remains unresolved and is accepted for 0.1.0 with the
project owner's approval on September 7, 2026.

Creating another workspace has not been verified as a workaround. There is no
confirmed reliable workaround yet. This limitation should be considered before
using an Omarchy workspace for keyboard-dependent work.

Follow-up reference: `omarchy-keyboard-latency-return`. Diagnostic observations
and candidate-specific test results are retained in
[implementation progress](implementation/PROGRESS.md). This exception does not
represent a passing keyboard test or waive unrelated release requirements.
