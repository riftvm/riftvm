Two worlds, deeply supported

Choose macOS or Omarchy.

macOS restore releases come from Apple. Omarchy uses a pinned, verified Factory image and defaults to Custom VirGL graphics rendered through ANGLE on Metal. Each Linux workspace can explicitly select Apple Virtio for compatibility; macOS uses native Apple Graphics.

  1. 01
    Built for macOS 27 and later

    Pick a signed IPSW from the refreshed catalog or let Apple resolve the newest version compatible with your Mac.

  2. 02
    Omarchy, ready to work

    Download a signed, verified factory image and complete guided owner setup. A newer factory creates a separate workspace and preserves your existing one.

  3. 03
    Reusable image downloads

    Reuse cached images when creating more machines. Omarchy creation still connects to verify the signed release manifest.

  4. 04
    Useful diagnostics

    Export version, host, and VM configuration details directly from Community & Feedback when asking for help.
